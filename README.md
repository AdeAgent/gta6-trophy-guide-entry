Leonida Platinum Ledger — a complete trophy guide and tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies carry a guide written in our own words, numbered steps where a trophy takes work, and numbered, linked sources with the date we read them: 55/55 names, 55/55 guides, 55/55 cited. On top of the checklist sit a five-stage roadmap to the platinum (about 200 hours, difficulty 4/10, one playthrough), an honest missables page (exactly one trophy is possibly missable, and even that flag is labelled unconfirmed), a spoiler setting that masks unearned story and PSN-hidden trophies, per-trophy counters for the grind trophies, and progress that saves in the browser and travels by JSON export/import. It runs entirely offline and makes no network request. Names, descriptions and grades are PlayStation's official text; every guide is our own writing, and where no source has confirmed a detail the guide says "not yet confirmed" instead of guessing. No Rockstar artwork, logos or styling are used.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```

Hand the entry in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies `app/` and `screenshots/` to the output directory and writes its `dossier.json`.
